# Micromouse
Stuart the Micromouse was created following the IEEE Micromouse Competition rules, built for a capstone project.
It traverses a (sized down) 8x8 physical maze to find the shortest path to the center. It is a mixture of Embedded, PCB design, controls systems, shortest path algorithms, and reinforcement learning.

The capstone project achieved IEEE Winnipeg Section 1st Place Prize.
